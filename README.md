# 六机器人相对定位与目标围捕仿真

本项目复现 *Concurrent Relative Localization and Distributed Target Fencing Without Persistent Excitation* 的数值实验。六个机器人通过完全图通信并跟踪同一移动目标。机器人 1 是唯一的源节点。两种测距方案利用机间距离和自身速度估计相对位置，并直接使用源节点广播的目标速度和加速度估计。

## 安装与运行

在本目录打开终端，使用 Python 3.10 或更新版本。建议创建虚拟环境，再在该环境中运行以下命令。运行时依赖为 NumPy 和 SciPy。本次复现使用 Python 3.13.7、NumPy 2.4.3 和 SciPy 1.18.1。

```sh
python -m pip install -r requirements.txt
python run.py
```

默认命令用主种子 `20260916` 分别运行三种方法，每种运行 240 s。以下命令分别用于快速检查安装，以及复现包含五组配对试验的完整统计。

```sh
python run.py --case proposed --duration 1
python run.py --repeats --jobs 3
```

完整试验共运行 11 个算例。`proposed` 和 `published_global` 各使用 `20260916` 至 `20260920` 五个种子，`current_only` 使用主种子。同一种子生成相同的初始条件及对应的测量噪声序列。`--jobs` 指定并行进程数，`--output` 可指定一个新的或空的输出目录。运行 `python run.py --help` 可查看全部选项。

## 三种方法

| 命令行名称 | 测量和算法 |
| --- | --- |
| `proposed` | 利用一段运动历史积累的测距和速度信息更新相对位移估计，再由各机器人计算围捕控制量。 |
| `current_only` | 将估计器的历史信息项替换为当前时刻的回归项，保留与主方法相同的更新增益和控制律，用于比较历史信息的作用。 |
| `published_global` | 使用带噪的全局位置测量，独立实现 Jiang 等提出的目标观测器和动态围捕控制器。[原文，IEEE Transactions on Automation Science and Engineering](https://doi.org/10.1109/TASE.2025.3596929) |

## 配置与输出

`config.json` 保存默认实验参数。积分步长为 0.005 s，测量噪声以 30 Hz 更新，每 0.1 s 保存一次结果。测距、速度分量和位置分量的高斯噪声标准差分别为 **0.1 m、0.05 m/s 和 0.1 m**。同一位置噪声标准差用于源节点的目标位置测量和全局位置基准的机器人位置测量。

| 适用方案 | 与表 I 对应的参数 | 运行取值 |
| --- | --- | --- |
| 两种测距方案 | 位置、速度及目标相对位置观测器增益 $(k_s,k_v,\kappa_s)$ | $(0.12,1.5,2)$，对应 `kp`、`kv`、`ks` |
| 两种测距方案 | $(\lambda_e,\gamma_e,\ell_e,\Gamma_e)$ | $(1,0.2,2000,0.3I_2)$ |
| 两种测距方案 | $(A_e,B_e)$，通信边权和源节点权重 | $(0.5,0.1)$，各边 $a_e=1$，$b_1=2$，其余 $b_i=0$ |
| 全部方案 | 距离界 $(d_s,D_s)$，微分器的 $L_j$ | $(0.45,12)$ m，$0.02$ m/s³ |
| 两种测距方案 | 微分器 $(\mu_0,\mu_1,\mu_2)$ | $(3,1.5,1.1)$ |
| 全局位置基准 | 微分器 $(\mu_0,\mu_1,\mu_2)$，源节点权重 | $(2,1.5,1.1)$，$1$ |
| 全局位置基准 | $(c_1,c_2,c_3)$，$(c_p,\gamma_p)$，$(c_a,\gamma_a)$ | $(3,2.37,0.18)$，$(5,4.2)$，$(0.5,2)$ |
| 全局位置基准 | 排斥增益 $k_\phi$，平滑函数 $\sigma(t)$ | 在 2.5 m 处按控制力比例匹配得到 $3.3635675\ldots$（表 I 取 3.36），$e^{-0.02t}$ |

默认目标轨迹与正文式（36）一致。初始位置在 $[1,7]\times[-6,0]$ m 内采样，任意两机器人初始间距至少为 1.3 m。初速度各分量的标准差为 0.12 m/s。全局位置基准的有效参数由 `published_baseline.py` 中的 `matched_config` 生成，并写入该算例 `summary.json` 的 `baseline_config` 字段。

程序默认将每次运行写入 `results/` 内的独立目录。根目录的 `summary.json` 汇总各方法的结果。三个主试验以方法名设立子目录，其他种子位于 `paired/<seed>/<case>/`。每个算例的 `trajectory.npz` 保存状态和轨迹，`metrics.csv` 保存逐时刻指标，`summary.json` 保存统计值。可用 `numpy.load` 读取轨迹。

如需核对实现，可从 `fencing/scenario.py` 查看目标轨迹、初始条件和传感器噪声，从 `fencing/core.py` 和 `fencing/target_motion.py` 查看相对定位、围捕控制与目标运动估计。`fencing/published_baseline.py` 实现全局位置基准，`fencing/study.py` 将各方法与机器人动力学一起积分。`fencing/geometry.py` 和 `fencing/results.py` 分别计算凸包几何量和统计指标。

## 核对主试验结果

默认设置保存 2401 个采样时刻，包括初始时刻和 240 s 终点。下表列出主种子的参考值，保留与论文相同的显示精度。全局位置基准直接估计全局坐标中的目标位置，表中两项相对估计指标只对两种测距方法给出。

| 指标 | 保留历史信息 | 仅用当前信息 | 全局位置基准 |
| --- | ---: | ---: | ---: |
| 平均边定位误差 $E_q$（m） | 1.26 | 2.78 | — |
| 平均目标相对位置误差 $E_s$（m） | 0.596 | 1.27 | — |
| 平均速度跟踪误差 $E_v$（m/s） | 0.0720 | 0.0841 | 0.131 |
| 平均质心误差 $E_c$（m） | 0.529 | 0.725 | 0.275 |
| 最后 40 s 的平均 $E_c$（m） | 0.302 | 0.684 | 0.118 |
| 目标在凸包内的采样比例（%） | 93.5 | 93.2 | 98.4 |
| 最小机间距离（m） | 1.36 | 1.37 | 1.53 |

计算 $E_q$、$E_s$、$E_v$ 时，先在每个采样时刻取各边或各机器人中的最大误差，再对指定时段取平均。$E_c$ 为机器人质心与目标之间的欧氏距离。五组配对试验的全程平均 $E_c$（跨种子的均值 ± 样本标准差）分别为 **0.547 ± 0.055 m**（保留历史信息）和 **0.271 ± 0.00383 m**（全局位置基准）。
